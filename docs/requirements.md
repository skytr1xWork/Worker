# Форматирование

- Ты не должен использовать форматирование часто.
- У бота есть свой стиль - ты его должен придерживаться.
- Никаких эмодзи, длинных тире, развернутых описаний.

Твоей главной задачей в стилистике - поддерживать общий стиль бота.

# Тех. задачи

В тех задачах твоя задача следующая:
1. Придерживайся оптимизации кода
2. Не используй фоллбеки. Лучше с ошибкой чем зажевать и не работать.
3. Не используй большие массивы и циклы которые могут навредить/задержать/замедлить сервер.
4. Никогда не меняй метаданные (авторство, название).
5. Имей в виду то, что бот делается как веб приложение, а не instance.
6. Не делай велосипед из того, что можно сделать без проблем и легче.

1. После каждого изменения/написания кода в ответе выкладывай краткую сводку по тому что и как ты реализовал.
